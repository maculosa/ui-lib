# ProComponent Introduction

ProComponent is an advanced component library built on Naive UI. It focuses on mid- and back-office application scenarios and aims to provide a more efficient development experience.

## Core Features

- 🚀 **Ready out of the box** - Built on Naive UI, offering a higher level of abstraction
- 📦 **TypeScript support** - Complete type definitions with reliable type inference
- 🎨 **Theme customization** - Inherits the Naive UI theme system and supports deep customization
- 🔌 **Plugin-based design** - A flexible extension mechanism that lets you bring in features on demand

## Component List

### ProTable

A high-performance table component with the following features:

- Automatic requests and data loading
- Column configuration persistence
- Custom column settings
- Bulk actions
- Inline editing
- Tree data display

### ProDescriptions

An advanced descriptions component for data display:

- Multiple layout options
- Responsive design
- Edit mode support
- Data linkage

### ProText

A text handling component that solves common text display problems:

- Automatic ellipsis
- Copy support
- Formatted display
- Status markers

### Watermark

A watermark component that protects sensitive information:

- Custom text and images
- Tamper-proof mechanism
- Global configuration

### NaiveProvider

A global configuration provider:

- Unified theme management
- Internationalization configuration
- Default prop configuration for components
