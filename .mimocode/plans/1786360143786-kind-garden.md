# ProForm Model 同步方案

## 问题分析
ProForm 在 `onMounted` 时创建内部 `formData`，之后与 `props.model` 独立。切换企业时更新 `formModel.product` 无法同步到 ProForm 内部。

## 实现方案

### 修改文件
`packages/procomponent/src/components/ProForm/src/index.tsx`

### 核心改动

1. **添加 model 变量跟踪**（第 41 行后）
   ```ts
   const lastModelSnapshot = ref<string>('')
   ```

2. **取消注释并优化 model watch**（第 184-193 行）
   ```ts
   watch(
     () => props.model,
     (newModel) => {
       if (!newModel || typeof newModel !== 'object') return
       
       const newSnapshot = JSON.stringify(newModel)
       if (newSnapshot === lastModelSnapshot.value) return
       
       lastModelSnapshot.value = newSnapshot
       
       // 同步新值到 formData，保留内部已有的字段
       Object.keys(newModel).forEach(key => {
         if (key in formData.value) {
           formData.value[key] = newModel[key]
         }
       })
     },
     { deep: true }
   )
   ```

3. **onMounted 中记录初始快照**
   ```ts
   onMounted(() => {
     if (props.defaultValue && Object.keys(props.defaultValue).length > 0) {
       formData.value = { ...defaultValue }
     } else {
       formData.value = createFormData()
     }
     // 记录初始快照
     lastModelSnapshot.value = JSON.stringify(props.model || {})
   })
   ```

### UniLinkChange.vue 配合改动

在 `formItemProps.onChange` 中清除产品值：
```ts
formItemProps: {
  onChange: (e: string) => {
    formModel.value.product = null  // 新增：清除产品选择
    getProductOptionsByCompany(e)
  }
}
```

## 验证步骤

1. 选择企业 A → 选择产品 → 切换企业 B → 产品框应为空
2. 确认提交时 formData 包含正确的产品值
3. 测试不影响其他表单操作（重置、提交等）
